## Test Environment Architecture Diagram

The diagram presents the architecture of a laboratory environment used for analyzing security events and detecting network attacks. The environment consists of several network segments separated by a firewall, as well as a SIEM-class system used for security log analysis.

The central component of the infrastructure is the pfSense firewall, which acts as both a router and a traffic control point between individual network segments. The firewall has Suricata IDS/IPS installed, which analyzes network traffic in real time and generates security event logs.

The environment is divided into three main network segments.

## WAN Network

The WAN segment represents an external network from which incoming traffic to the infrastructure may originate. The WAN interface of the pfSense firewall allows simulation of internet traffic as well as potential attack attempts.

## LAN Network

The LAN segment represents the internal network of the organization. In this part of the infrastructure there is a client computer running Windows 11.

A Wazuh agent is installed on the system, which collects system logs and sends them to the management server. Additionally, the system runs Sysmon, which enables detailed monitoring of system events such as:

- process creation

- registry modifications

- network connections

This provides enhanced visibility into endpoint activity.

## OPT Network (Attacker Network)

The OPT segment is used to simulate the actions of a potential attacker. This network contains a Kali Linux machine used to perform penetration testing and generate malicious traffic directed at the LAN network.

## Log Analysis System (SIEM)

Security event analysis is performed by a server running Ubuntu Server, where the Wazuh Manager is installed.

The Wazuh platform functions as a SIEM system, enabling aggregation, analysis, and correlation of security events originating from multiple sources.

Logs generated by Suricata are stored in the eve.json format. These logs are then transferred from the pfSense firewall to the Ubuntu server using the SSH protocol, where they are further analyzed by the Wazuh system.
